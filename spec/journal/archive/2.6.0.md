## Land the trace contract draft and make trustworthiness the design criterion
*#138 · PR #140*

The trust analysis that shaped the contract uses the formula that a real guarantee equals a criterion
a human wrote in advance multiplied by a code check, which places cairn's verification in four
quadrants: suite mechanical assertions are human times code, the only complete guarantee and the
least used; `expect` is human times model; derived assertions are model times code, the substance of
not trusting the green; and per-run LLM adjudication is what cairn replaces. Two adversarial rounds
rejected a blanket freeze-ratification ceremony, since rubber-stamping is worse than no ratification
because it gives the tool an alibi. Review found two substantive defects, both fixed in the contract:
provenance was lost because suite merges user criteria into the frozen array with no origin marker,
so freeze now records `origin` additively as `user`, `derived` or `unknown`, with older skills
reading as unknown and failing closed; and heal was mapped for only one of three real layers, so heal
events now carry `layer: locator | step` while outcome-heal is expressed as discover kinds under
`phase: heal`. The largest remaining gap identified was trusting the red, meaning environment flake,
tracked as a separate axis.

## Grounding freezes run-specific query strings, producing permanently failing scripts
*observation, no code change*

When the same behavioural POST fired twice in one run, grounding tried to distinguish the two
requests by including the query string, freezing an assertion of the form
`.../cart/add-carts?buyRequestIds=586738`. That query value is issued fresh per run, so replay always
fires with a new id and the assertion can never be satisfied, a structurally false failure. The
knock-on cost is that outcome-heal is powerless, because the recovery criterion is that same embalmed
assertion, so rediscovery is doomed regardless of what it does, wasting 12 calls and 65k tokens and
polluting server state through repeated rediscovery. The engine proposal is for grounding to freeze
`urlIncludes` at path level by default, since query values are likely run-specific dynamic data and
therefore cannot be replay-grade assertions.

## Include the starting URL in the suite case hash
*#131*

`hashCase` fingerprinted only `intent`, `expect` and `assertions`, but discover freezes the effective
start URL as `steps[0]`, so the URL directly affects replay content; changing only a case's URL let
the cache pass as an exact match and silently replay against the stale target, exactly the leak the
staleness check was meant to prevent. The effective starting URL is now part of the hash material, so
both repointing a case URL and changing the suite base URL read as stale. The honest one-time cost is
that existing frozen skills were hashed without the URL, so the first run after upgrade forces one
rediscovery per case, a false-stale in the safe direction.

## Implement the trace event sink seam so the engine emits the contract
*#143 · #138*

The `TraceSink` port is `emit(event): void`, synchronous and fire-and-forget, called inline with
throws swallowed, because a trace is evidence and not control flow and a dead sink must never change
a verdict. `Tracer` and `TraceScope` are internal envelope stampers handling monotonic `seq`, `ts`
and `runId`; since `startTrace()` is the only construction path, seq 0 being the header is
structurally guaranteed. Emission points cover discover action and gate events, pipeline step, heal
and assertion events, locator-heal events in `run.ts` plus a self-trace for bare mode, and suite
header, case and freeze events. Existing callbacks are unchanged and the sink is purely additive:
with no sink configured the Tracer is never constructed, so cost and behaviour are unchanged. The
`freeze` event is emitted by suite because its payload's `caseHash` is a suite concept the core never
learns. Grounding-drop reporting needed six sites rather than four, because suggestions covered by
default grounding are reported as drops only when that default did not hold, so only real drops enter
the trace.
