The recorded order demo is available at https://cairn-order-demo.vercel.app.
The Vercel builder first runs the existing source and engine hash verification,
then serves the six recorded stages and a runnable source archive as static files.
The hosted config and order endpoints use the fixture's existing order contract;
no LLM endpoint, model credential, payment, or persistent order storage is deployed.

The hosted viewer was checked in a browser for discovery, zero-call replay,
work-grade proof, and the defect stage's failure and evidence-retention disclosure.
The API returned 200 for original and changed variants and 500 for the broken
variant. The original recording hashes remain unchanged. The source archive also
contains the hosting builder and adapter to keep the deployment reproducible.

External developers have not yet tested the demo. The example README now contains
the trial tasks and evidence to collect; no usability results are invented. Main
README positioning waits for that feedback, so this work does not close the issue.
