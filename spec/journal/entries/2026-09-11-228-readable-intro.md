# #228 — 소개문을 짧은 단계 설명으로 정리

사용자가 README 소개문의 가독성을 지적했다. 반복되는 비유와 무료·제품 대비 표현을
걷어내고, JSON 테스트라는 결과를 먼저 소개한 뒤 Discover → Replay → Repair 세 단계를
짧은 문장으로 나눴다. CLI·임베드 사용 안내는 한 문장으로 줄이고 42회 대 7회 측정은
두 항목으로 분리했다. 루트와 npm에 동일하게 반영했다.

사용자가 직접 제거한 비용표 제목의 대시는 유지하고 npm에도 맞췄다. 그래프, 두 비용표,
Features 이후는 바꾸지 않았다. 검증: npm 전용 제목·설치·절대 링크 차이를 제외한 전체
내용 일치, 선택 영역 이후 내용 보존, diff 공백 검사 통과.

state 변화: #228 소개는 짧은 결과 설명·세 단계·측정 수치 순서로 읽힌다.
