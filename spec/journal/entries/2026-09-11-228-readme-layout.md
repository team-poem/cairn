# #228 — 기존 README 구성 안에 호출 그래프 배치

사용자는 모델별 달러를 나란히 놓은 표가 모델 가격 순위처럼 읽힌다는 피드백을 전달했고,
기존 README 포맷을 유지하면서 Features 바로 위에 그래프 하나를 배치하도록 요청했다.
`codex/228-codex-benchmark`에서 Measured 제목과 달러 표를 짧은 호출 측정 설명으로
바꾸고, 원본 기록으로 생성한 누적 LLM 호출 그래프를 마지막 요소로 배치했다.

그래프는 Sol·Terra·Luna 각각의 동일한 7→42 대 7→7 추이를 표시한다. 세 모델을
합산하거나 평균 낸 값이 아니다. Claude의 42→7은 원 PR 보고값으로 출처를 구분한다.
달러 추정·토큰 원본과 Sonnet 비용 SVG는 그대로 보존하고 상세 문서에서 제공자별로
나누어 보여준다. 이름 변경을 버틴 다중 로케이터와 아직 측정하지 않은 self-heal도 구분했다.

검증: 벤치마크 삽입 부분을 제거하면 두 README가 PR 기반 커밋 `3a2378fa`와 바이트
단위로 일치한다. npm README에는 원 작성자가 추가한 secrets 항목만 유지한다.
기존 제목 순서·Features 직전 단일 그래프·두 README 내용 일치를 확인했다.
읽기 전용 반증 리뷰가 세 모델의 실행별 관측을 독립 집계하고 SVG 재생성 일치를 검증했다.
Chrome으로 1200px와 840px 너비를 렌더링해 선과 글자의 겹침을 수정했고 잘림이 없음을
확인했다. Node 구문 검사와 diff 공백 검사를 통과했다. 엔진 변경이나 유료 재측정은 없다.

반영한 교훈: 측정 조건의 각주만으로 표가 유도하는 비교를 막을 수는 없다. 소개 페이지의
그래프는 증명하려는 비교 축을 직접 보여주고, 서로 다른 비용 집계 기준은 상세 자료로
분리한다. 이 구분을 문서 구성과 원본 기록을 검사하는 그래프 생성기에 반영했다.

state 변화: #228 README는 기존 구성과 제목을 유지하며 모델 내부의 재생 효과를 중심으로
소개한다. 원본 데이터와 달러 환산 근거는 모두 상세 문서에서 추적 가능하다.
