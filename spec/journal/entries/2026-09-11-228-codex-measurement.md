# #228 — Sol·Terra·Luna 실측

`ee4dfe3105360e7471ba14c77542177998267dcf`를 빌드한 뒤 깨끗한 상태에서 세 모델을 측정했다.
같은 세 여정·6회·두 방식·4회차 v2 변경을 유지했고 추론 수준은 모두 medium이었다.
모델별 상한은 160호출이며, 세 모델은 격리된 서버·Chrome으로 동시에 실행했다.

## 결과

- 108/108 성공. 재생 45회는 모두 LLM 0호출, 복구·재동결 0회.
- 총 300회 LLM 호출. Sol 98회, Terra 98회, Luna 104회.
- 300회 모두 토큰 필드를 보고했다. 달러 비용은 모두 미상이며 비용 비교·교차점·SVG는 보류했다.
- 로그인→장바구니→주문의 6회 누적값:
  - Sol: 42호출·506,120토큰 → 7호출·84,088토큰.
  - Terra: 42호출·504,711토큰 → 7호출·83,956토큰.
  - Luna: 42호출·448,690토큰 → 7호출·74,978토큰.
- Luna의 폼은 30호출 → 4호출이다. 동일한 호출 비율을 가정하지 않고 관측값을 그대로 보존했다.

README 두 곳의 Measured 절을 다시 썼다. Claude의 기존 API 정가 환산액과 Codex의 토큰 수를
구분하고, 다중 로케이터에 의한 생존과 self-heal의 두 층을 유지했다. 이번에도 실제 복구는
발생하지 않아 #230의 복구 전용 측정은 여전히 필요하다.

`docs/benchmarks/228-codex.md`는 전체 표·조건·재실행 명령을 담고,
`228-codex.json`은 원본 보고서의 시도별 관측과 요약·해시를 보존한다. 절대 출력 경로·스택·
중복 ledger는 제외한 생성 자료다. 원본은 gitignored `bench/results/pr228-{sol,terra,luna}/`에 있다.
사전 파일럿은 본 측정에 합산하지 않았고 실패 후 재측정해 결과를 고른 시도도 없다.

검증: 타입 검사·빌드·의존 경계, 워크스페이스 1,164개와 벤치 147개 테스트 통과.
별도 반증 리뷰에서 캐시 쓰기 중복 집계·재연결 경고·모델 전환을 확인해 회귀 테스트와 함께
수정했고 재검토를 통과했다. 측정 JSON의 합계는 원본 시도별 토큰·호출 수와 대조했다.
