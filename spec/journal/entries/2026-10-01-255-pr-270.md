# Deploy the verified order demo on Vercel

_Drafted from [#270](https://github.com/team-poem/cairn/pull/270) by amazon7737. Edit this in place; do not delete and re-add it._

The six-stage order demo is now deployed at https://cairn-order-demo.vercel.app. Add a reproducible Vercel builder and two small hosted API functions that reuse the existing fixture's order contract. The builder verifies the original recording and engine hashes before exporting static evidence and the runnable source archive. Recorded engine and shop sources remain unchanged; no model endpoint, credential, payment, or persistent order store is deployed.

Include the hosting adapter in the downloadable source, document deployment commands, and provide concrete newcomer trial tasks. Real user feedback has not been collected, so main GitHub/npm README positioning remains a follow-up.
