# Demonstrate ActionPolicy enforcement

_Drafted from [#271](https://github.com/team-poem/cairn/pull/271) by solp721. Edit this in place; do not delete and re-add it._

## What

Add a runnable ActionPolicy example to the quickstart. A scripted client proposes deleting a record, the policy rejects it, and discovery continues with an allowed save.

## Why

“Never” in an intent is model guidance. This example shows how the existing policy API enforces a restriction before execution, with checks against driver calls and fixture state.
