# #228 — 표 바로 위에 용어 안내 배치

사용자 요청으로 소개의 단계 목록과 중복 호출 요약을 제거하고 두 문장으로 줄였다.
그래프 뒤, 첫 비용표 바로 위에 Journey·Discover·Replay·Heal의 짧은 정의와
방식별 동일 여정 6회 누적 기준을 추가했다. Heal이 이번 측정에서 발생하지 않았음을
명시했다. Claude 비용 설명에서 중복된 6회 기준 문장만 제거했다.

검증: 그래프 → 용어 안내 → 비용표 순서, 모든 그래프·비용표·나머지 내용 보존,
루트와 npm의 전체 내용 일치(배포용 제목·설치·링크 예외), diff 공백 검사 통과.
state 변화: 제품 소개는 짧게, 벤치마크 용어는 표를 읽기 직전에 설명한다.
