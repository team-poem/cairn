# #228 — 제공자별 선그래프로 변경

사용자는 게이지처럼 보이는 막대 대신 이전의 선그래프 형태를 요청했다. Claude 위·Codex
아래 배치와 짧은 README 설명을 유지하고, 같은 축척의 누적 호출 선그래프로 바꿨다.

Codex는 원본 실행별 관측점을 그대로 사용한다. Claude는 원 작성자의 6회 누적 42회와
탐색 후 재생 누적 7회, 재생 5회 모두 0호출이라는 보고를 사용한다. 반복 탐색의 중간
호출은 공개되지 않아 시작 기준점과 최종점만 점으로 표시하고 점선으로 연결했다.
점선이 중간 실행의 실측이 아님을 그래프와 상세 문서에서 밝힌다. 재생 선은 첫 실행
7회와 이후 0회라는 보고에서 도출했으며, 원본 실행별 JSON으로 가장하지 않는다.

검증: 두 SVG 결정적 재생성, 막대 없음, Claude 반복 탐색은 두 점만 보유, 원본 호출
집계와 일치, Features 이후 원문 보존, Node 구문·diff 공백 검사를 확인했다.
Chrome에서 1200px와 840px 너비로 렌더링해 겹침과 잘림이 없음을 확인했다.
실측 데이터·달러 환산값·엔진 동작은 바꾸지 않았다.
