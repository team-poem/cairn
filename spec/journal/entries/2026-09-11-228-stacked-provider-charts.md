# #228 — 제공자별 그래프를 상하로 분리

사용자가 Claude와 Codex 그래프를 상하로 나누고 그래프 영역의 글자를 줄이도록 요청했다.
두 README의 기존 벤치마크 구간을 짧은 설명과 동일 크기·축척의 막대그래프 두 장으로
교체했다. Claude 위, Codex 아래, 그 다음 Features 순서다. 나머지 내용은 그대로다.

각 그래프는 주문 여정의 모델별 6회 누적 LLM 호출 42회 대 7회를 보여준다. 모델 간
합계나 평균이 아니다. Claude는 작성자의 원 README `8e61a82`에서 보고한 Sonnet·Opus
합계를 출처와 함께 저장했고, Codex는 기존 시도별 원본에서 합산한다. Claude의 중간
실행별 원본 없이 추이를 만들지 않도록 두 그래프 모두 합계 막대를 사용한다.

반복되는 설명과 축 눈금을 줄이고 모델명·방식·단위·값을 남겼다. 자세한 조건과 출처,
가격 비교의 한계는 상세 문서에 유지했다. 멀티 로케이터 생존과 self-heal 미측정 구분은
소개 문구에도 유지한다.

검증: 두 README 내용 일치·그래프 순서·구간 밖 원문 보존, 원 작성자 표와 관측 토큰의
호출 수 대조, 두 SVG의 결정적 재생성, Node 구문·diff 공백 검사를 통과했다.
Chrome으로 1200px와 README 840px 너비에서 렌더링해 글자 겹침·잘림이 없음을 확인했다.
새 LLM 호출, 원본 측정값 수정, 버전 상향은 없다.

state 변화: #228의 소개 그래프는 제공자별로 분리된 호출 합계 두 장이다.
