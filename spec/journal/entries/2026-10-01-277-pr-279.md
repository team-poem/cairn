# Refresh prepared unpublished versions

_Drafted from [#279](https://github.com/team-poem/cairn/pull/279) by solp721. Edit this in place; do not delete and re-add it._

## What

Allow Prepare release to rerun for the same unpublished version, appending late journal entries without rewriting the existing archive or duplicating entries.

Preserve an open release PR's title and body, create a new draft if the previous PR was closed, and skip empty commits. Fix the generated comparison link's missing previous version.

## Why

PRs merged after release preparation enter develop, but their journal entries remain outside the prepared archive. Previously, rerunning preparation failed because the version was already bumped.

This makes that refresh part of the normal workflow instead of requiring manual archive commits. Published, tagged or main-merged versions are rejected; concurrent develop changes fail rather than being overwritten. Retried journal jobs also recognize already-archived PRs.
