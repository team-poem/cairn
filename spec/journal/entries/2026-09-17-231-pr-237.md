# Preserve exact refs across guarded documents

_Drafted from [#237](https://github.com/team-poem/cairn/pull/237) by amazon7737. Edit this in place; do not delete and re-add it._

## What

Keep exact observation references on pages containing measurable same-origin, cross-site, and nested iframes. Each captured document retains its original document, frame owner, and semantic nodes; validation protects the globally ordered accessibility cohort, including initially empty frames.

Frozen targets keep the existing page-wide `text`, `role`, `index`, and `nth` fields. Document identities remain private to the Chrome adapter. Unknown frame topology, shadow coverage, or unavailable measurements still preserve candidates while withholding references.

## Why

Previously, a single iframe removed exact references from every candidate on the page. Simply issuing references for the main document would allow changes in another frame to silently move the replay ordinal. The new document guards validate that shared ordinal pool and reject frame replacement, navigation, reordering, cohort changes, and superseded observations.

The live fixture proves same-origin nested documents and an actual cross-site sibling (`127.0.0.1` / `localhost`). MCP can omit loaded nested cross-site documents from its AX tree; incomplete coverage remains a conservative fallback. Multi-context validation uses bounded closing revision checks and does not claim a browser-wide atomic transaction.

A dedicated Ubuntu CI job reproduces the pinned MCP 1.8.0 fixture. Existing MCP 1.3.0 compatibility jobs remain unchanged.
