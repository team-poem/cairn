# Mirror each release to GitHub Packages

_Drafted from [#243](https://github.com/team-poem/cairn/pull/243) by solp721. Edit this in place; do not delete and re-add it._

## What

Publish the same build a second time to GitHub Packages as `@team-poem/cairn-engine`, right after the npm publish. npm stays the registry people install from.

## Why

The repository page has never listed a package, because GitHub only shows what is published to its own registry, and that registry only accepts scoped names. The name is switched for the one publish command and restored right after.

The mirror is skipped when the version is already there, and if it fails the tag and the release still go out, with the failure shown as a warning. `workflow_dispatch` is added so an already released version can be mirrored by hand. `GITHUB_TOKEN` covers it, no new secret.

- The step order and the skip conditions were read through against the existing npm publish path; this cannot be exercised before it reaches main
