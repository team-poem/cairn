# #228 — Codex 벤치 어댑터

`codex/228-codex-benchmark`에서 PR #228의 Sol·Terra·Luna 측정 인계를 진행한다.
엔진은 변경하지 않고 벤치의 LLM 어댑터와 비용 기록 경로를 확장했다.

- Codex CLI 0.146.0의 실제 JSONL 파일럿은 비용 없이 입력·출력·캐시 토큰을 반환했다.
  입력에 포함된 캐시 읽기·쓰기를 분리하고, 출력에 포함된 추론 토큰은 다시 더하지 않는다.
- `budgetMode: "calls"`는 명시적인 `maxCalls`로만 실행을 제한한다. 달러 제한과 함께
  선언할 수 없으며, 비용 미상은 미상으로 남긴다. 기존 달러 제한 모드의 중단 규칙은 유지한다.
- 모델 호출은 임시 디렉터리에서 사용자 설정·프로젝트 지침·shell·web·세션 저장을 끄고
  실행한다. 실패·취소를 기록하고 120초 제한을 적용한다. 자동 재시도는 없다.
  CLI 내부의 재연결 진단은 보존하되 최종 완료 상태로 성공을 판단한다. 다른 모델로
  전환됐다는 이벤트가 나오면 토큰을 보존하고 해당 시도를 실패로 기록한다.
- 교차점이 없는 정상 비교에서 `null + 1` 때문에 "1회부터 저렴"으로 표시되던 SVG를
  `no crossover`로 수정했다. 비용 미상의 보고서 footer도 `unknown`으로 표시한다.
- 세 모델의 본 측정 설정은 기존 Claude의 여정·버전 일정·지연·maxSteps를 유지한다.
  추론 수준은 모두 medium, 호출 상한은 모델당 160회다.

실제 Chrome의 scripted smoke는 3/3 성공했다. Luna 이동 파일럿은 4/4 성공했으며,
매번 탐색 6호출·62,872토큰, 한 번 탐색 후 재생 3호출·31,043토큰이었다.
재생은 0호출, 토큰 필드는 모두 보고됐고 달러 비교는 보류됐다.
이 파일럿은 2회 일정으로 연결을 확인한 것이며 README의 6회 측정에는 합산하지 않는다.

회귀 테스트는 먼저 실패를 확인한 뒤 구현했다. 기존 테스트·픽스처는 수정하지 않고
사례를 추가했다. 전체 검증은 워크스페이스 1,164개·벤치 147개, 타입 검사·빌드·의존 경계
검사를 통과했다. 본 측정 결과는 후속 저널에 기록한다.

state 변화: 없음. 본 측정 및 README 갱신 진행 중; self-heal 전용 측정은 #230의 범위다.
