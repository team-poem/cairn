# Check the URL before spending a model call on page guidance

Navigation can finish while the host is preparing guidance. Until [#357](https://github.com/team-poem/cairn/pull/357),
`discover()` and `explore()` could ask the model to act on the old page, only to discard its answer.
Both loops now check the URL after accepting guidance and before calling the model. If the URL
differs, even because it became known or unknown, the loop discards the observation and retries
under the existing expiration limit. The retry prompt uses the new observation's URL or `(unknown)`.

On a stable guided turn this costs one extra `driver.observe()`, without a new element snapshot.
The pre-call check adds no read when the provider returns no usable guidance. Navigation can still
happen during the model call, so the post-response and pre-dispatch checks remain necessary.
