# #228 — 그래프 아래 비용표 복원

사용자는 벤치마크 문장의 의미가 불분명하고, 그래프 아래에 Claude 기존 비용표와
Codex 환산 비용표가 모두 보여야 한다고 지적했다. 상세 링크로 대체한 결정은 요구와
달랐다. 두 README에 Claude 6행과 Codex 9행을 별도 표로 복원했다.

순서는 쉬운 측정 설명 → Claude 선그래프 → Codex 선그래프 → Claude 비용표 →
Codex 비용표 → Features다. 각 행은 같은 모델·여정의 두 실행 방식에 대한 6회 누적이다.
Claude는 원 PR의 제공자 보고 정가 환산액이며 보조 모델 포함을 표시했고, Codex는
캐시 할인을 적용한 Standard 단가 가정의 추정액으로 소수점 네 자리와 ~를 사용했다.
기존 상세 원본·환산 JSON·그래프는 수정하지 않았다.

어려운 멀티 로케이터 문장을 역할·위치로 버튼을 찾았다는 설명으로 풀고, 실제 AI
수리가 발생하지 않아 self-heal 측정이 남았음을 명시했다. 기존 소개와 Features 이후는
그대로 유지하고, npm README는 패키지명·설치·절대 링크 외에는 루트와 일치시켰다.

검증: 15행의 비용·호출 수를 상세 원본과 Decimal 반올림으로 대조, 두 README 완전
내용 일치, 그래프·표 순서, 변경 구간 밖 원문 보존, diff 공백 검사를 통과했다.
state 변화: 비용 결과는 README에서 직접 읽을 수 있고 상세 링크는 근거 자료를 제공한다.
