# #228 — Codex 달러 환산액 추가

사용자 요청으로 `codex/228-codex-benchmark`에서 기존 관측 토큰을 달러로 환산했다.
새 LLM 호출 없이 2026-09-11에 확인한 OpenAI Standard·짧은 컨텍스트 공식 단가를
일반 입력·캐시 읽기·캐시 쓰기·출력에 각각 적용했다. Standard는 CLI가 보고한 티어가
아닌 계산 가정이며, 구독의 추가 청구액으로 해석하지 않는다.

로그인→장바구니→주문의 방식별 6회 누적 추정액은 Sol $1.1513 → $0.1502,
Terra $0.3788 → $0.0566, Luna $0.0407 → $0.0049다. README 두 곳은 추정액과
호출 수를 표시하고 상세 문서는 기존 토큰 표와 9개 여정별 달러 표를 함께 보존한다.

단가 스냅샷·정수 나노달러 환산 스크립트·생성 JSON을 추가했다. 원본 측정 JSON,
런타임 비용 미상 값과 비교 가능 여부는 그대로다. 새 엔진 동작이나 공개 API는 없다.

검증: Python Decimal로 18개 방식별 값과 6개 합계를 독립 대조했다. 원본이 HEAD와
동일함을 확인했고, 입력 해시·재생성 일치·README 내용 일치·Node 구문·diff 공백
검사를 통과했다. 이전 구현의 타입 검사·빌드·1,311개 테스트 결과가 유효하며,
이번 문서·환산 자료 변경에서 전체 벤치마크를 재실행하지 않았다.
