# Only comment on active merge requests

_Drafted from [#296](https://github.com/team-poem/cairn/pull/296) by amazon7737. Edit this in place; do not delete and re-add it._

## What

Only create or update pending cairn-pingu comments while a develop PR has an active `needs-merge` request. Recheck the label immediately before publishing so cancelling a request also suppresses queued notifications.

## Why

PR #295 received a merge-blocker comment while it only had a review label. Review and `no-merge` labels alone should remain silent; blockers should be explained when a maintainer requests merging. Existing notices can still be resolved after merge or closure. Merge eligibility is unchanged.

This script change activates when merged into develop, which the existing trusted merge workflow checks out. It is independent of trigger PRs #294 and #295. The journal bot can record this decision from the PR on merge.
